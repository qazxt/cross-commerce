# FindsIndex 复刻流水线 v2

## 核心理念
**观察 → 复刻 → 对比 → 完善** 循环迭代

## 工作流程

```
第 N 轮开始
    │
    ▼
┌─────────────────────────────────────────────┐
│ 1️⃣ 观察代理                                 │
│ - 访问原站 findsindex.com                   │
│ - 发现新功能/页面/模块                      │
│ - 输出：《观察报告》                        │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 2️⃣ 复刻代理                                 │
│ - 接收《观察报告》                          │
│ - 开发实现对应功能                          │
│ - 输出：《开发完成报告》                    │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 3️⃣ 对比代理                                 │
│ - 对比原站 vs 我们的实现                    │
│ - 列出差距和遗漏                            │
│ - 输出：《对比报告》                        │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 4️⃣ 完善代理                                 │
│ - 根据《对比报告》进行优化                  │
│ - 修复问题，补全功能                        │
│ - 输出：《完善报告》                        │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 📊 汇总报告 → 给你确认                       │
│ - 本轮完成内容                               │
│ - 差距清单                                   │
│ - 下一轮建议                                 │
└─────────────────────────────────────────────┘
    │
    ▼
🔄 你确认后 → 进入下一轮循环
```

## 4 个代理职责

| 代理 | 职责 | 输出 |
|------|------|------|
| **观察代理** | 访问原站，发现新功能/页面 | 《观察报告》 |
| **复刻代理** | 根据观察报告开发实现 | 《开发完成报告》 |
| **对比代理** | 对比原站 vs 我们的实现 | 《对比报告》 |
| **完善代理** | 根据对比结果优化修复 | 《完善报告》 |

## 目标
**当前阶段：复刻 FindsIndex 海淘代购平台**

每一轮循环都让我们的网站更接近原站，直到核心功能对齐。

## 使用方法

1. 告诉我"开始复刻"或"下一轮"
2. 我自动执行：观察→复刻→对比→完善
3. 每轮最后给你汇总报告
4. 你确认后进入下一轮
