# FindsIndex 首页优化方案

> 制定时间：2026-05-31
> 目标：从专业设计和产品角度提升首页体验

---

## 一、当前问题诊断

### 1.1 布局结构问题

| 问题 | 现状 | 影响 |
|------|------|------|
| **Banner 过大** | 紫色渐变占首屏 50%+ 空间，信息密度低 | 用户需要大量滚动才能看到内容 |
| **右侧装饰图不协调** | Dior 运动裤图放在 banner 右侧，和"发现好物"主题脱节 | 视觉干扰，用户困惑这是什么商品 |
| **统计卡片太像 Dashboard** | 4 个大数字卡片，没有电商气质 | 不像购物网站，像数据后台 |
| **分类品牌横向滚动** | 当前分类和品牌都是横向滚动 | 桌面端浪费空间，用户需要手动滚动 |

### 1.2 视觉设计问题

- **紫色 Banner 太抢眼** — 和整体页面色调不协调，像科技产品官网
- **搜索框对比度不足** — 在紫色渐变上不够突出
- **缺乏品牌辨识度** — 没有独特的品牌色和视觉语言

### 1.3 信息架构问题

- **首屏信息过载** — Banner + 搜索 + 标签 + 装饰图，信息密度高但重点不突出
- **用户动线不清晰** — 用户进来不知道该看哪里、做什么

---

## 二、优化目标

1. **搜索为核心** — 用户来就是找商品的，搜索应该是最突出的
2. **品牌感** — 从"科技网站"转型为"潮流购物搜索引擎"
3. **呼吸感** — 合理的留白和间距，内容不拥挤
4. **清晰动线** — 用户一眼看到：搜索 → 分类 → 品牌 → 推荐

## 四、具体优化项

### 4.1 Banner 区域 → 搜索引导区

| 修改项 | 当前 | 优化后 |
|--------|------|--------|
| **高度** | 400-520px 大海报 | 200-280px 精简区 |
| **背景** | 紫色渐变动画 | 浅灰/白底 + 细微纹理 |
| **标题** | 超大字体 + 副标题 | 中等字体 + 简短 slogan |
| **搜索框** | 有，但不够突出 | **核心元素，最大最宽** |
| **装饰图** | Dior 运动裤 (不搭) | 删除��改为轮播推荐商品 |
| **热门搜索** | 透明标签 | 实体标签按钮 |

### 4.2 分类导航

| 修改项 | 当前 | 优化后 |
|--------|------|--------|
| **布局** | 横向滚动 | 4-6 列网格 (桌面) |
| **卡片样式** | 带背景色的卡片 | 简洁图标 + 名称 + 数量 |
| **交互** | hover 缩放 | hover 阴影 + 边框高亮 |

### 4.3 品牌展示

| 修改项 | 当前 | 优化后 |
|--------|------|--------|
| **布局** | 横向滚动 | 8 列网格 (桌面) |
| **展示** | 图标+名称 | Logo + 名称 + 商品数 |

### 4.4 精选商品

| 修改项 | 当前 | 优化后 |
|--------|------|--------|
| **列数** | 4 列 | 4 列 (保持) |
| **商品卡片** | 当前样式 | 增大图片比例，减少文字 |

### 4.5 统计信息

| 修改项 | 当前 | 优化后 |
|--------|------|--------|
| **位置** | 独立 section，4 大卡片 | 精简为 1 行小字 |
| **样式** | 大数字 + 渐变 | 小数字 + 标签，融入背景 |

## 五、视觉风格调整

### 色彩方案

```
主色：#4F46E5 (Indigo)
辅色：#9333EA (Purple)
背景：#F9FAFB (浅灰)
文字：#1F2937 (深灰)
辅助文字：#6B7280 (中灰)
```

- **去掉紫色渐变动画** → 改用简洁的白色/浅灰背景
- **品牌色只用于交互高亮** (hover, 按钮, 链接)
- **统计数据去掉彩虹色** → 统一使用品牌色

### 排版

- **标题层级**：H1 32px → H2 24px → H3 18px
- **正文字号**：14px 基础，16px 正文
- **间距**：使用 4px/8px/16px/24px 的倍数系统
